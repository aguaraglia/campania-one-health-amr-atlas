# Materiali di curatela

Questa cartella contiene gli input usati per ricostruire il catalogo e i layer: decisioni di inclusione, esummary PubMed, lo stato dei testi integrali, il disclaimer EpiCentro consultato per la licenza AR-ISS e le risposte Nominatim delle cinque strutture nominate (AOU Federico II, AOU Vanvitelli, Ospedale Monaldi, AOU Ruggi d'Aragona, AORN Sant'Anna e San Sebastiano). Non contiene i materiali esclusi di dati.regione.campania.it, di ICAAROweb, delle ASL, dell'ARPAC, del catalogo open data dell'IZS del Mezzogiorno né del rapporto OsMed.
